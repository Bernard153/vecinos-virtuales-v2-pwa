Política de Privacidad

Vecinos Virtuales - Versión 2.1 PWA

Ultima actualizacion: 12 de Octubre de 2026

✓ COMPROMISO CON TU PRIVACIDAD

Respetamos tu privacidad y protegemos tus datos conforme a la Ley 25.326 de Protección de Datos Personales (Argentina).

1. DATOS QUE RECOPILAMOS

Datos básicos:

  • Nombre completo
  • Email
  • Teléfono
  • Barrio
  • Contraseña (encriptada)

Datos opcionales:

  • Ubicación geográfica (solo si la activas)
  • Imágenes que subas
  • Contenido que publiques
  • Fotos, audio y GPS capturados por el Sistema de Alertas (solo si lo activás)

Datos del Sistema de Alertas Vecinales:

  • Fotografias capturadas automaticamente durante una alerta
  • Grabacion de audio durante una alerta
  • Ubicacion GPS en tiempo real durante una alerta
  • Codigo de desactivacion de 3 digitos (elegido por el usuario)

2. CÓMO USAMOS TUS DATOS

  • ✓ Crear y gestionar tu cuenta
  • ✓ Conectarte con vecinos de tu barrio
  • ✓ Mostrar tus publicaciones
  • ✓ Permitir que otros vecinos te contacten
  • ✓ Mejorar el servicio
  • ✓ Enviar alertas de seguridad a moderadores y vecinos (si activás el sistema)

3. DATOS VISIBLES PARA OTROS USUARIOS

Al registrarte, aceptas que estos datos sean visibles para otros vecinos:

  • Tu nombre
  • Tu telefono
  • Tu barrio
  • Tus publicaciones

Sistema de Alertas Vecinales: Cuando una alerta es aprobada por los moderadores, las siguientes evidencias son visibles para todos los vecinos del barrio:

  • Fotografias capturadas durante la alerta
  • Grabacion de audio
  • Ubicacion GPS y recorrido
  • Tu nombre de usuario

Las alertas rechazadas o canceladas (susto/nada) son borradas permanentemente.

3.5. SISTEMA DE ALERTAS VECINALES

El Sistema de Alertas es voluntario y gratuito. Al activarlo, la app captura:

  • Fotos cada 2 segundos (máximo 30)
  • Audio en tiempo real (hasta 3 minutos)
  • Ubicación GPS cada 5 segundos

Estos datos se suben inmediatamente a nuestros servidores y se comparten con los moderadores de tu barrio para validar la alerta.

Importante:

  • Si detenés la alerta con tu código y elegís "fue un susto" o "nada", todos los datos se borran inmediatamente
  • Si la alerta se envía, los moderadores revisan la evidencia antes de publicarla a los vecinos
  • Las alertas aprobadas se eliminan automáticamente a las 48 horas de ser resueltas
  • Este sistema no reemplaza al 911. Es complementario
  • El uso del sistema es a cuenta y riesgo del usuario
  • El sistema está enfocado exclusivamente en casos de robo e inseguridad

4. SISTEMA DE ALERTAS VECINALES

El sistema de alertas de seguridad captura y sube datos en tiempo real cuando el usuario lo activa:

  • Fotos automaticas con la camara del dispositivo (cada 2 segundos, maximo 30 fotos)
  • Grabacion de audio del entorno (hasta 3 minutos)
  • Ubicacion GPS en tiempo real (cada 5 segundos)

Estos datos se suben en tiempo real a servidores seguros (Supabase) y son revisados por los moderadores del barrio antes de publicarse a otros vecinos.

Si la alerta es falsa, el usuario puede borrar TODO lo capturado con su codigo de 3 digitos.

Si la alerta es rechazada, los datos se borran a las 24 horas. Si es resuelta, a las 48 horas.

5. LO QUE NO HACEMOS

  • NO vendemos tus datos a terceros
  • NO compartimos tu email sin consentimiento
  • NO compartimos tu ubicacion exacta (excepto durante una alerta activa)
  • NO recopilamos DNI, datos bancarios o medicos
  • NO usamos los datos de alertas para fines comerciales
  • NO conservamos las evidencias de alertas canceladas (se borran inmediatamente)

6. SEGURIDAD

Tus datos se almacenan en Supabase (cumple estándares internacionales):

  • ✓ Conexión encriptada (HTTPS)
  • ✓ Contraseñas encriptadas
  • ✓ Acceso restringido

6.1 SISTEMA DE ALERTAS VECINALES

El Sistema de Alertas Vecinales es un servicio complementario de seguridad comunitaria.

  • Las alertas son validadas por moderadores del barrio antes de publicarse
  • El usuario puede cancelar una alerta en cualquier momento con su codigo de 3 digitos
  • Las alertas canceladas se borran inmediatamente (fotos, audio y GPS)
  • Las alertas aprobadas se conservan por 48 horas despues de ser resueltas
  • El sistema NO reemplaza al 911 ni a las autoridades oficiales
  • El uso del sistema es a cuenta y riesgo del usuario
  • El sistema esta enfocado exclusivamente en casos de robo e inseguridad
